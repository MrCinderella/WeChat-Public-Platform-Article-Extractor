# 公众号合集文章提取器

把公众号「合集 / 专辑」里的全部文章批量抓取下来，导出为 Markdown。

界面程序，双击即用，目标电脑**无需安装 Python**。

---

## 一、快速开始

1. 双击 `公众号合集文章提取器.exe`
2. 粘贴合集链接（形如 `https://mp.weixin.qq.com/mp/appmsgalbum?__biz=...&album_id=...`）
3. 选择输出目录，勾选格式（默认 Markdown）
4. 点「开始提取」，等待完成

完成后在输出目录得到每个文章一个 `.md` 文件。

> 目录里保留的是源码，运行 `python album_gui.py` 即可。
> 已编译好的 exe 可在上级目录 `公众号合集提取器_备份/` 中取用，
> 或按文末说明自行重新打包。

---

## 二、界面说明

| 区域 | 说明 |
|---|---|
| **合集链接** | 粘贴链接，实时校验格式是否正确 |
| **导出选项** | 输出目录、导出格式、失败重试次数、断点续传开关 |
| **操作** | 开始 / 停止 / 打开输出目录 |
| **进度** | 当前文章、总进度、成功失败统计 |
| **运行日志** | 完整过程记录，可另存为文本 |

支持勾选三种输出：

- **Markdown** — 标题 + 元数据（公众号/作者/发布时间/原文链接）+ 正文
- **HTML** — 保留原样式，图片本地化到同名 `_images` 目录
- **元数据表格** — 一张 Excel，列出所有文章的标题、作者、发布时间、链接

---

## 三、遇到失败怎么办

微信对高频访问有风控，批量抓取时可能出现少量失败。

**推荐做法：**

1. 等待 10～30 分钟，让访问频控恢复
2. 勾选 **「跳过已存在（断点续传）」**
3. 再次点「开始提取」

已抓取成功的文章会被跳过，只补齐缺失的那些。这样既能补全，又不会因重复请求再次触发限流。

> 提示：进度统计里的「跳过 N」就是本次无需重下的文章数。

---

## 四、同名文章如何处理

合集里可能存在标题相同但内容不同的文章（例如同一主题的不同版本）。

程序会按出现顺序自动添加序号后缀区分：

```
合并报表编制的十大原理.md
合并报表编制的十大原理（2）.md
合并报表编制的十大原理（3）.md
```

不会互相覆盖，也不会丢篇。

## 五、常见问题

**Q：提示「链接中缺少 album_id」**
A：需要的是**合集/专辑链接**，不是单篇文章链接。单篇文章链接里没有 `album_id`。

**Q：提示「不是有效的微信文章链接」**
A：请在微信中打开合集，点右上角「复制链接」，直接粘贴过来。

**Q：多数文章失败，提示 403 / 访问被拒**
A：触发了微信频控。按第三节处理，等待一段时间后用断点续传补齐。

**Q：单篇文章很慢？**
A：程序在每篇之间保持 3～5 秒随机间隔，这是**刻意设计的**，用于降低被风控的概率，不建议改小。

**Q：文章内容不完整 / 图片显示异常？**
A：Markdown 中的图片会指向同名 `_images` 目录，移动文件时请把 `.md` 和 `_images` 目录一起移动。

## 六、从源码运行

```bash
pip install -r requirements.txt
python album_gui.py
```

### 文件说明

| 文件 | 作用 |
|---|---|
| `album_gui.py` | 图形界面程序入口 |
| `album_core.py` | 核心逻辑：链接解析、列表抓取、正文提取、导出 |
| `scraper.py` | HTTP 请求与页面解析（含反爬处理） |
| `exporters.py` | Markdown / HTML / Excel 导出器 |
| `album_extractor.spec` | PyInstaller 打包配置 |

### 自行打包

```bash
pip install pyinstaller
pyinstaller album_extractor.spec --noconfirm --clean
```

产物在 `dist/公众号合集文章提取器.exe`（单文件，约 60 MB）。

## 七、技术要点

抓取合集文章列表时，有两个容易踩的坑，程序已处理：

1. **列表接口只支持游标分页**——用 `begin_msgid` + `begin_itemidx` 定位下一页，普通的 `begin=` 偏移量会被服务端忽略。
2. **`continue_flag` 返回字符串 `'1'` 而非整数 `1`**——按整数比较会导致只取到第一页就误以为抓完了。

另外，微信有时会返回 HTTP 200 但正文为空，因此程序不只看请求成功，还要求标题非空、正文有实质内容，避免生成空文件。
